# Phase 5 — Checklist

One subtask = one pull request.

## Subtasks

- [ ] **Track changed files + ranges** — Record the files and ranges an AI execution modified, linked to the task and execution.
- [ ] **Diff preview UI** — Show a diff of the AI changes for a task.
- [ ] **Accept / Reject / Request changes** — Implement the three review actions, each updating task state and appending history.
- [ ] **Inline highlight + attribution** — Decorate AI-modified ranges and show "Changed by <agent>" on hover.

## Verification

- [ ] `npm run check` passes.
